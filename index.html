The Garden

Notes in progress

Unfinished thinking, published anyway. Each note is marked with how grown it is: seedling, budding, or evergreen.

budding

Websites as places

The personal sites I remember feel like places, not documents. You visit them. That's why this one is an island: the same content can be read two ways, but only one of them feels like going somewhere.

evergreen

Two lenses, one source

Spectacle should never cost the reader anything. Everything here is written once as plain HTML; the island is generated from it. If the island ever gets in the way, the Read button is always there. Related: local time.

seedling

A website that shares your clock

What if a site knew it was 2am where you are and dimmed the lights? A small thing, but it makes the page feel like it's in the same room as you. Early thoughts, built into this island.

Colophon

Hand-built with plain HTML, CSS and JavaScript. No framework, no build step, no cookies, no trackers. The island is a seeded isometric map drawn in SVG from the sections of this page, and lit by your local clock. Type is Instrument Serif and Geist. Sounds are generated live in the browser.

Inspired by Bruno Simon, Maggie Appleton, Josh Comeau, Rauno Freiberg, gwern.net, Lynn Fisher, and the whole personal web.
